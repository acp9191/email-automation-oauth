Privacy Policy

Personal Email Automation · Last updated October 12, 2026

Personal Email Automation ("the app") is a private tool that runs only on its owner's computer, for the owner's own Gmail account. It has no other users. This policy describes what the app does with Google user data.

Data the app accesses

  • Gmail, read-only (gmail.readonly). The app searches the inbox with a narrow query for Verizon bill notification emails. It reads those messages' sender, subject, date, body, and attachments to confirm that a message is the monthly bill and to find the billing period.
  • Gmail, send-only (gmail.send). The app sends the bill as a PDF attachment to one email address that the owner configures in advance. It also sends the owner a notice if a run fails. It cannot read mail with this permission.

The app does not request permission to delete, modify, or label messages, or to access contacts, calendars, or files.

How data is used

The app uses Gmail data only to detect the bill notification and forward the bill to the owner's configured work address. It does not use Gmail data for advertising, profiling, analytics, or training machine-learning models.

Storage

Everything the app keeps is stored locally on the owner's computer:

  • OAuth tokens, in files readable only by the owner's user account.
  • Downloaded bill PDFs.
  • A local database of processing records: Gmail message IDs, billing periods, file names and checksums, run status, and an audit log of emails sent.

The app does not store full email bodies. The data is not uploaded to any server operated by the app or anyone else. The owner can delete all of it at any time by deleting the app's data folder, and can revoke Gmail access at myaccount.google.com/permissions.

Sharing

Google user data is not sold, shared with, or transferred to any third party. The only outbound transfer is the bill email itself, which the app sends from the owner's own account to the owner's own configured address.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
